# ESP-VoCat 喵伴

## 简介

ESP-VoCat 喵伴是一款智能 AI 开发套件，搭载 ESP32-S3-WROOM-1 模组，1.85 寸 QSPI 圆形触摸屏，双麦阵列，支持离线语音唤醒与声源定位算法。

## 硬件规格

- **主控**: ESP32-S3-WROOM-1 (Xtensa dual-core 32-bit LX7)
- **显示屏**: 1.85寸 QSPI 圆形触摸屏
- **存储**: 16MB Flash
- **音频**: 双麦阵列，支持声源定位

## 支持功能

- 离线语音唤醒
- AI 对话 (小智 / Qwen / DeepSeek)
- MCP 协议 IoT 控制
- 触摸交互 (单击/双击/长按/三击)
- 情绪学习模式
- 定时提醒
- 待机表情动画

## 编译烧录

**环境准备**:
```bash
source /home/hrong/workspace/code/esp-idf-5.5/export.sh
```

**编译**:
```bash
python3 scripts/release.py esp-vocat
```

**烧录**:
```bash
idf.py -p /dev/ttyACM0 flash
```

**查看日志**:
```bash
idf.py -p /dev/ttyACM0 monitor
```

**串口调试** (115200 波特率):
```bash
# Linux/WLS2
picocom -b 115200 /dev/ttyACM0

# Windows: 使用串口工具连接 COM10
```

## 触摸交互

| 手势 | 触发条件 | 功能 |
|------|----------|------|
| 单击 | < 350ms 松开 | 播放音效 |
| 双击 | 350ms 内连续两次 | 播放双音效 |
| 长按 | > 1.2秒后松开 | 切换静音模式 |
| 三击 | 500ms 内连续三次 | 进入/退出情绪学习模式 |

## 情绪学习模式

三击进入情绪学习模式，用于教儿童识别不同表情：

- 开心、伤心、生气、惊讶、困惑、困了、喜欢、平静
- 单击切换下一个表情
- 长按退出
