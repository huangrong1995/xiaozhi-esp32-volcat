# ESP-VoCat 喵伴

## 简介

ESP-VoCat 喵伴是一款智能 AI 开发套件，搭载 ESP32-S3-WROOM-1 模组，1.85 寸 QSPI 圆形触摸屏，双麦阵列，支持离线语音唤醒与声源定位算法。

## 硬件规格

- **主控**: ESP32-S3-WROOM-1 (Xtensa dual-core 32-bit LX7)
- **显示屏**: 1.85寸 QSPI 圆形触摸屏
- **存储**: 16MB Flash
- **音频**: 双麦阵列，支持声源定位

## 支持功能

- 离线语音唤醒
- AI 对话 (小智 / Qwen / DeepSeek)
- MCP 协议 IoT 控制
- 触摸交互 (单击/长按/左右滑/外圈抚摸/甩动)
- 情绪学习模式、设置页
- 统一喝水/整点提醒队列
- 两级节能 (关屏 / 浅睡眠) + 外圈电容唤醒
- 待机表情动画

## 交互模式与状态机

交互以**屏幕为主，外圈为辅**。所有物理输入先被归一化为统一手势（`Gesture`），再交给集中分发入口 `OnGesture()`，按当前模式（`Mode`）路由到对应行为。`Chat` 是唯一根状态，情绪学习与设置页都有显式退出路径和 30 秒无操作自动退出兜底。**单击/长按/左滑/右滑/外圈抚摸/甩动**是全部手势（上下滑保留给未来功能，当前不占用）。

### 模式切换表

| 当前模式 | 手势 | 目标 |
|---|---|---|
| `Chat`（对话） | 屏幕右滑 | 进入设置页 |
| `Chat` | 屏幕左滑 | 进入情绪学习 |
| `Chat` | 屏幕单击 / BOOT 键 | 开始/停止对话 |
| `EmotionLearning` | 屏幕长按 | 退回 `Chat` |
| `EmotionLearning` | 30s 无操作 | 自动退回 `Chat` |
| `Settings` | 屏幕长按 / 左上 ‹ | 退回 `Chat` |
| `Settings` | 30s 无操作 | 自动退回 `Chat` |

> 任意手势都会重置节能倒计时和模式空闲计时。

## 屏幕手势交互

### 日常模式 `Chat`（根状态）

| 手势 | 功能 | 说明 |
|------|------|------|
| 屏幕单击 | 开始/停止一次对话 | 唯一的语义点击源 |
| 屏幕长按 | 取消/操作提示反馈 | 不再切换静音、不再记录喝水 |
| 屏幕右滑 | 进入设置页 | |
| 屏幕左滑 | 进入情绪学习 | |
| 屏幕上下滑 | 保留未用 | 留给未来音量/快捷功能 |
| IMU 甩动 | 播放"被摇晃"反馈 | 仅在此模式生效 |
| 外圈抚摸/滑动 | 轻量互动反馈 | 仅做陪伴反馈，不改变模式、不切换对话 |
| BOOT 物理键 | 开始/停止对话 | 对话兜底；启动阶段仍进入 Wi-Fi 配网 |

> 手势与对话的关系：**滑动绝不切换对话**，只有单击和 BOOT 键才切换对话。

### 情绪学习模式 `EmotionLearning`

用于教儿童识别不同表情（开心、伤心、生气、惊讶、困惑、困了、喜欢、平静）。进入后屏幕显示一个**旋转拨盘**：8 个刻度环绕当前情绪名，儿童**用手指绕圈拖动拨盘**来选择情绪（顺时针下一个、逆时针上一个），选定情绪名呈现在中央。

| 手势 | 功能 |
|------|------|
| 手指绕拨盘旋转 | 选择情绪（顺时针/逆时针翻页） |
| 屏幕长按 | 退出情绪学习，退回 `Chat` |
| 屏幕上下滑 | 退出情绪学习，退回 `Chat` |
| 屏幕单击 | 轻量互动反馈（拨盘以外的空白处） |
| 外圈抚摸 | 只做陪伴反馈，不切换内容 |
| 30s 无操作 | 自动退出，退回 `Chat` |

屏幕下方有**「开始」按钮**：按下后宠物脸示范当前情绪，逐张卡片自动播放（单击=跳下一张，任意滑动=取消回到拨盘），全部演示完播放完成反馈并回到拨盘。

> 屏幕中央有提示「转动选择 · 长按退出」，儿童无需记忆手势。

### 设置页 `Settings`

调节屏幕亮度与音量（0-100 步进）：

| 手势 | 功能 |
|------|------|
| 点击 − / ＋ | 步进调节，实时生效 |
| 点击左上 ‹ | 退回 `Chat` |
| 任意滑动 / 长按 | 退回 `Chat` |
| 30s 无操作 | 自动退回 `Chat` |

> 进入设置/情绪学习等非对话屏会**强制结束当前对话**（停止听/说并收起对话覆盖层）。

## 提醒与喝水

提醒（喝水周期 + 5 个整点日程）统一进单一队列，一次只弹一条。提醒为最高优先级表现层，显示期间屏幕手势由提醒主导，模式导航被遮挡，直到处理完。

| 操作 | 行为 |
|------|------|
| 屏幕单击 | 确认；若为喝水提醒则记录喝水打卡并播放成功反馈，否则仅确认 |
| 屏幕长按 | 忽略本次提醒（可重复，最多 N 次后静默，延迟再提醒） |
| 无操作 | 延迟后再提醒，最多 N 次后静默 |

> 喝水打卡不再使用隐式手势（移除"长按=打卡"），统一为提醒出现时的**屏幕单击确认**。整点提醒处理后 15 分钟内不弹喝水提醒，避免两条提醒背靠背轰炸。

## 节能与唤醒（两级节能）

| 阶段 | 无操作阈值 | 动作 | 唤醒词 |
|---|---|---|---|
| ① 轻度节能（关屏） | 30s（可配） | 关闭背光/关屏，CPU 不降频 | ✅ 仍可用 |
| ② 深度节能（浅睡眠） | 60s（可配） | 复用 `PowerSaveTimer` 降频 + 浅睡眠，关闭唤醒词/音频 | ❌ 靠触摸唤醒 |

- 屏幕为最大耗电源，主要省电靠①关屏。
- 两级阈值通过 `config.h` 的 `DISPLAY_SLEEP_TIMEOUT_SECONDS` / `LIGHT_SLEEP_TIMEOUT_SECONDS` 宏配置。
- 提醒与模式状态为高优先级表现层，显示期间不进入休眠。
- 仅在根 `Chat` 状态、无提醒、且 `Application::CanEnterSleepMode()` 为真（Idle、无音频/对话）时进入浅睡眠。

### 唤醒优先级

| 唤醒源 | 物理动作 | 优先级 |
|---|---|---|
| **外圈电容触摸垫** | 抚摸/拍打宠物身体 | ⭐ 首选 |
| LCD 触摸屏 | 点击屏幕 | 次选（预留，待硬件验证） |
| BOOT 物理键 | 按键 | 兜底 |

从浅睡眠醒来后：恢复背光、恢复 CPU 频率、重新开启唤醒词与音频输入，回到可对话状态。

> 注：②深度节能中的浅睡眠需 `CONFIG_PM_ENABLE` 生效，LCD 触摸与 BOOT 的 GPIO 唤醒源受极性与唤醒能力影响（见 `config.h` 的 `VOCAT_ENABLE_GPIO_WAKEUP`）；外圈电容垫为始终启用的首选唤醒源。此部分为待硬件验证的后续项，本说明书聚焦预期行为。
